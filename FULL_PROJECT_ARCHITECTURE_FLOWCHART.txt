3. MONGODB DOCUMENT SCHEMA RELATIONSHIPS
================================================================================

  ┌────────────────────────┐         ┌────────────────────────┐
  │       COLLECTION       │         │       COLLECTION       │
  │        "users"         │         │       "projects"       │

  │ _id : ObjectId         │         │ _id : ObjectId         │
  │ username : String      │         │ title : String         │
  │ email : String         │         │ subtitle : String      │
  │ password : BCryptHash  │         │ description : String   │
  │ role : "ROLE_ADMIN"    │         │ techTags : Array<Str>  │
  └────────────────────────┘         │ imageUrl : String      │
                                     │ displayOrder : Integer │
  ┌────────────────────────┐         │ details : Document {   │

                                                                   │
                                                                   ▼

                                                                   │
                                                                   ▼
 React App getImageUrl() resolves relative URL (/uploads/abc.png)
 into absolute backend URL: http://localhost:8080/uploads/abc.png
