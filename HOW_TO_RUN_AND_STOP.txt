          DEVPORTFOLIO FULL-STACK PROJECT — HOW TO START & STOP GUIDE
================================================================================

This project consists of 2 applications:
  1. BACKEND  : Spring Boot 3 + Embedded MongoDB (Runs on http://localhost:8080)
  2. FRONTEND : React 19 + Vite + TypeScript (Runs on http://localhost:3000)

--------------------------------------------------------------------------------
PART 1: HOW TO STOP THE RUNNING PROJECT
--------------------------------------------------------------------------------

METHOD A: In Your Terminal Window
  - Click on the terminal window running the server.
  - Press: Ctrl + C (and type 'Y' if prompted).

METHOD B: Force Stop Using Terminal Commands (If Port is Busy)
  - To stop Backend (Port 8080):
      npx kill-port 8080
      OR in PowerShell:
      Get-Process -Id (Get-NetTCPConnection -LocalPort 8080).OwningProcess | Stop-Process -Force

  - To stop Frontend (Port 3000):
      npx kill-port 3000
      OR in PowerShell:
      Get-Process -Id (Get-NetTCPConnection -LocalPort 3000).OwningProcess | Stop-Process -Force

--------------------------------------------------------------------------------

STEP 1: START THE BACKEND SERVER (Spring Boot)
